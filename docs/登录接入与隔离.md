# WMS 登录接入与隔离

## 接口兼容

参考 k3_wms_android 的 ApiService、LoginPresenter、UserModel、AESUtil.encrypt(String) 和 AppHeaderProvider：

- POST `app`，外层为 `functionCode=AppLogin` 与 `data`。
- data 包含 userCode、AES/CBC/PKCS5Padding 加密后 Base64 的 password、employmentType=false、appVersion、imei、language（CN/EN）。
- DEV/TEST 使用测试服务，PROD 使用生产服务；配置位于 lib/shared 的 AppEnvironment。
- 成功要求 result=true 且 Token 非空；业务失败显示后端 message。
- 登录后的业务请求经 WmsGateway，使用 SESSION_MOBILE_USER_TOKEN；HTTP 401 或业务 message=请重新登录触发退出。不虚构刷新 Token 接口。
- 当前实现常规员工账号密码登录；临时工 employeeCode、仓库选择等完整 WMS 功能需独立需求。
- imei 字段保持历史命名，值优先 AID_AndroidID，否则使用安装级随机 ID；不申请电话硬件权限。后端若绑定旧应用安装标识，需联调确认。
- appVersion 为本应用 VERSION_CODE；服务端若对版本号做校验，需要使用接口认可的版本号。

## 本地配置

复制 wms-auth.properties.example 为 wms-auth.properties，填写 WMS_AES_KEY / WMS_AES_IV。只保存到本地被忽略文件，CI 用同名凭据环境变量。AES 固定参数是现有服务端协议兼容要求，客户端包含参数不等同于服务器秘密保管方案；后续升级需与服务端同步。

密码只在输入与请求期间驻留内存，不保存到 DataStore、Bundle 或日志。登录与 WMS 业务请求关闭报文日志，Token 经 Android Keystore AES-GCM 加密后存入安装级 DataStore；应用禁用系统备份。

## 登录与导航

启动恢复会话时显示加载状态；恢复失败转到登录页并提示。登录成功才装配业务导航。退出/环境切换/过期时销毁业务 ViewModelStore 与返回栈。旧请求带会话 generation，只能使发起请求时的会话失效，不能清除新登录。

设置页显示账号、仓库及退出按钮；仅 Debug 可切换环境。重启后采用构建指定环境，已存会话环境不符时要求重新登录。退出是本地清除凭据；原接口未提供服务端注销能力。

## 缓存与公开示例

业务 DataStore 和 Room 使用环境 + 账号 + 仓库的哈希作为独立名称。账号切换不共享缓存。Repository 固定绑定创建时的 DAO，避免旧响应写入新账号数据库。缓存保留供同账号离线查看，不作自动跨账号迁移；旧版 app.db / app_storage 不迁移到 WMS 会话。

原 posts 示例使用独立 JSONPlaceholder 客户端，始终不带 WMS Token；首页列表仍然是能力示例，并未冒充 WMS 业务数据。

## 真机验收

1. 正确账号登录、错误密码提示、断网/超时、连续点击登录。
2. 登录后杀进程重启，验证恢复；退出后返回键不能回到业务页。
3. 测试/生产环境切换需重新登录，旧请求晚返回不能污染新会话。
4. 两账号、两仓库的 KV/Room 数据互不串用。
5. Keystore 恢复异常回到登录；Release 无环境切换与 HTTP 报文日志。
6. 接口返回请重新登录或 HTTP 401 回到登录页；迟到的旧401不清除新账号。

自动化验证使用 MockEngine，不需要真实账号，不代表线上登录已验证。真实账号、服务端版本限制和设备绑定需使用团队测试账号联调。
