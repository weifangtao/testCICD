## 发布步骤

1. 执行 `./gradlew test :app:lintStagingDebug :app:assembleStagingDebug`，保存报告。
2. 设置 ANDROID_HOME 和 JDK，执行 `bash ci/verify-template.sh --build`，保留耗时与产物记录。
3. 完成登录真机验收（见登录接入与隔离.md），确认测试、正式接口及版本号。
4. Jenkins 配置签名、WMS 参数和必要的分发凭据；手动运行测试包流水线，记录链接。
5. 通过团队评审后更新 CHANGELOG 版本，提交并创建版本标签，再实际发布。
6. 确定维护人、升级方式和反馈入口。公共模板升级先在接入分支验证，再合并业务项目。

当前 CHANGELOG 的 Unreleased 不代表已发布；本地构建不代表 Jenkins/蒲公英已验收。
